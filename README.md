# phinze/homebrew-tap

Casks that aren't in Homebrew yet. Each one is meant as a bridge until it
lands in [homebrew-cask](https://github.com/Homebrew/homebrew-cask), and gets
dropped from here once it does.

```sh
brew install --cask phinze/tap/<cask>
```
